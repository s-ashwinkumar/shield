## What got done overnight

### Plan 4 — worktree-in-container correctness ✅ (the big one)
Kills the **silent wrong-code testing** bug. Root cause found: git worktrees created on the host store an absolute host path (`/Users/ashwin/code/rhythms/.git/...`) that doesn't resolve in the container (repo mounts at `/workspaces/rhythms`), so git — and anything using it — failed for worktrees in-container, and tests fell back to main.
- `_rdev_lib.sh` helpers: `rdev_docker_exec`, `rdev_container_path`, **`rdev_container_prep`** (aliases the host path → mount in-container + `mise trust`s the worktree), `rdev_lock_diverged`, **`rdev_share_deps`** (symlinks `node_modules`/`BUNDLE_PATH`/`pypoetry` from mainline; scoped in-container reinstall only if a lockfile diverged).
- `rstream` now runs `rdev_container_prep` + `rdev_share_deps` on worktree creation.
- **Verified live:** fresh worktree → git resolves in-container, deps symlinked in seconds, `webui` unit test runs against the *worktree*.
- `rhythms/.cursorindexingignore` excludes `.claude/worktrees/` (fixes Cursor indexing overload).
